# docs/

The long form behind `AGENTS.md`. `AGENTS.md` holds the rules a session must
follow and stays short; each file here holds the reasoning, the history and the
detail behind one of its sections, so a rule is never undone for want of
knowing why it exists. When a rule changes, change both.

| File | AGENTS.md section |
| --- | --- |
| `architecture.md` | Layering rules |
| `first-launch.md` | First launch |
| `generation.md` | Download lifecycle, How a generation runs |
| `library.md` | The library |
| `app-target.md` | The app target's shape |
| `adding-a-model.md` | Adding a model or a backend |
| `reference-pictures.md` | Starting from a picture, Upscaling |
| `build-and-release.md` | Build & run, Tests |
| `model-weights.md` | Model weights, Vendored code |
| `debugging.md` | Debugging hooks |

Measured figures are in `BENCHMARKS.md` at the root; deferred work in `ROADMAP.md`.
