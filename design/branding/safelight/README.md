# Safelight branding concepts

Three raster concept boards generated with the built-in image-generation tool.
Each contains light and dark app icons plus matching logo lockups.

- `01-lightfold.png`: folded copper ribbon Z; strongest compact silhouette.
- `02-afterglow.png`: optical horizon and vertical light rays; more abstract and
  more intricate at small sizes.
- `03-zephyr.png`: flowing organic Z; expressive silhouette and flat emblem.

These are exploration boards, not production icon exports. The existing website
and macOS app icon remain unchanged pending a selection. Full generation and edit
prompts are retained in `PROMPTS.md`.
